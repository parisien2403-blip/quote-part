# Quote-Part

PWA de partage du budget du couple : calcule chaque cycle (du 25 au 24) ce qu'il faut virer à l'épouse quand tous les revenus et prélèvements passent par un seul compte.

- Prorata des charges familiales = (salaire + ½ aides) de chacun ÷ total revenus + aides
- Aides (CAF…) partagées 50/50
- Montants par paliers datés (ex. plan Banque de France)
- Date / montant modifiables mois par mois (prélèvement décalé, sauté…)
- Suivi des virements faits, récap partageable, sauvegarde JSON

Données stockées localement (localStorage). Déploiement : GitHub Pages, branche `main`, dossier racine.
